# NestJs Blog & Events API

A backend built with **NestJs**, serving as a foundation for managing **blog articles** and **events**.

## ✨ Features
- Blog **articles** management
- **Events** management

## 📚 Documentation
- [ARCHITECTURE.md](./ARCHITECTURE.md) - Detailed architecture documentation specific to this project
- [NESTJS_ARCHITECTURE_GUIDE.md](./NESTJS_ARCHITECTURE_GUIDE.md) - General NestJS architecture guide for future projects

## ⚙️ Configuration
Create a `.env` file at the root of the project and use the values from **.env.example** as a reference.

## 🚀 Installation

```bash

# Clone the project
git clone ...

# Navigate into the directory
cd repo_name

# Install dependencies
npm install

# Start the server
npm run start:dev
``` 

## Endpoints

Une fois lancé, une documentation swagger est disponible à http://localhost:3000/swagger
